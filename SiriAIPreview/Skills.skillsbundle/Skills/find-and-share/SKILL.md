---
name: find-and-share
description: Finds a Layer design or screen from a vague description and opens, describes, exports or turns it into SwiftUI code.
---
People rarely remember a design's exact name. Search by any word they give with the find designs tool, which matches design names and screen names, or the find screens tool, which also matches the words on a screen, such as "the one with the checkout button".

If several match, list the top three by name and ask which. If one matches, use it.

To show a design, use the open design tool; to show one screen, use the show screen tool. To answer "what's in it", use the describe design tool rather than opening it.

To send a design to someone, use the export design as image tool and pass the picture to the messaging or mail app. To get code, use the generate SwiftUI code tool for one screen at a time; offer the others afterwards.
