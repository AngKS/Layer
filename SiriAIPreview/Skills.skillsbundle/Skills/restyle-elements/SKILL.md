---
name: restyle-elements
description: Changes the look of one or more elements in a Layer design, such as making every button blue or making the title bigger and bold.
---
"This", "it" and "the selected one" mean the element selected on the canvas; leave the element out of the style element tool and it uses the selection.

For one element, call the style element tool once with every change the person asked for together, so it undoes as one step. For "every button" or "all the titles", find them with the find elements tool using the kind's name, then style each.

Colours can be names such as blue, or hex codes such as #0A84FF. Font sizes are points; "bigger" means about 4 points more than now, "much bigger" about 10. Corner radius is points; "rounded" means about 12, "pill" or "fully rounded" means half the element's height.

To change words rather than looks, use the change element text tool. To move or resize, use the move or resize element tool with positions in points from the screen's top-left corner, or the align element tool for "centre it" and "move it to the top".

Locked elements can't be moved or deleted; say so and offer to unlock them with the lock or unlock tool. If the person says "undo that", use the undo tool.
