# Rotation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every element on the board (not screens) can be turned by a knob, a two-finger twist and a Rotation field, alone or several as one rigid piece, and the turn shows everywhere the element does: canvas, hit testing, lasso, code, thumbnails and voice.

**Architecture:** Each element stores an angle (`rotation`, degrees clockwise) beside its upright `frame`; one geometry type, `TurnedRect`, works out the turned shape from the two, and every reader that cares (rendering, hits, lasso, snapping, selection drawing) asks it. Turning goes through one `AppModel` API (`beginTurn` / `turnSelection(by:snaps:)` / `endTurn`) used by the knob, the twist, VoiceOver and, for several things, a `TurnSession` that keeps the pivot and a baseline so nothing drifts. Ink is turned where it is placed on the PencilKit canvas, and turned back when the canvas rebuilds a drawing.

**Tech Stack:** Swift 6, SwiftUI, UIKit gesture recognisers, PencilKit, Swift Testing (unit), XCUITest (UI), XcodeGen.

**Spec:** `docs/superpowers/specs/2026-11-18-rotation-design.md` (approved 2026-11-18). Read it first; this plan argues from it.

## Global Constraints

- iPadOS 27, Xcode 27.2. Unit tests are Swift Testing (`@Test`, `#expect`); UI tests are XCUITest.
- The project is generated: run `xcodegen generate` after adding or removing a file.
- Angle storage: `rotation: Double?` in degrees, nil meaning 0, normalised to 0..<360, clockwise positive. Shown as 0–359°.
- No file version bump: `rotation` is decoded with `decodeIfPresent` and written only when set.
- Rendering order for a turned element is `.frame` → `.rotationEffect` → `.offset` (or `.position`).
- Ink is turned **after** the stretch to the frame, about the frame's centre.
- Snapping: multiples of 45° within ±4°, for the knob and the twist only, never the field.
- Twist thresholds: about 8° of turn before about 8% change of distance.
- Rotation field ruler: 2 pt of finger drag per degree, 1° of barrel roll per degree, wraps at 360.
- Screens never turn; a selection containing a screen has no knob, no twist and no Rotation field. Locked elements don't turn.
- Exactly one `.onPencilSqueeze` (the existing one in `StylePanel`); none may be added.
- Nothing is repositioned to dodge the pencil palette.
- Each turn is one undo step: a knob drag, a twist, a scrub, a typed value, a voice command.
- Don't install to the user's iPad ("AKS Mini") without the user's go-ahead: another session (layer-30) is testing on it.

**Commands used throughout.** Make this branch its own simulator once (Task 1, Step 0), then:

## Review Focus

1. **Undo, then turn again.** After a turn of several things is undone, the next turn must start from where things now are (knob at 0°), never jump them back to a stale baseline. → Task 5, `undoAfterATurnFormsTheNextTurnFromWhereThingsAre`.
2. **A typed angle out of range.** Typing −90 or 450 in the Rotation field gives 270 or 90, not 0 or 359. → Task 6, `aTypedAngleWrapsRatherThanStops`.
3. **Several things on a half-size screen and the open canvas at once.** Canvas, screen and element points convert through each host's placement; turning a mixed set by 90° and back must land every frame exactly. → Task 5, `turningSeveralThingsAndBackPutsEverythingExactlyWhereItWas` uses a screen at scale 0.5 plus a floating note.
4. **A twist that starts after one finger has begun dragging the element.** The few points it moved and the twist undo as one step, and the next one-finger drag works normally (no stuck drag). → Task 9, `aTwistAfterTheFingerBeganDraggingIsOneUndoStep`, plus the device checklist.
5. **A turned element in a row of the Stack export.** Elements side by side become an `HStack`; the turned one must still turn in place, once. → Task 7, `elementsSideBySideTurnInTheirRow`.

### Task 2: Turned ink, and no second turn when the canvas rebuilds a drawing

**Files:**
- Modify: `Layer/Document/DrawingInk.swift` (`canvasStrokes`; new `drawing(_:id:keepingTurn:about:)`)
- Modify: `Layer/Canvas/DrawingSync.swift` (`Shown` gains `rotation`; `changes(for:in:reach:)` rebuilds a turned drawing with the new function)
- Test: `LayerTests/DrawingTests.swift`, new suite `TurnedDrawingTests` in the same file (it reuses that file's private `stroke(from:to:)` and `cross(at:)`)

**Interfaces:**
- Consumes: `Rotation.rotate`, `DesignElement.setRotation`, `resolvedRotation` (Task 1).
- Produces:
  - `canvasStrokes` places ink: translate by −natural.min → stretch to the frame → translate to frame.min → **rotate by `resolvedRotation` about the frame's centre**.
  - `static func drawing(_ strokes: [PKStroke], id: UUID, keepingTurn degrees: Double, about centre: CGPoint) -> DesignElement?`: strokes as they lie on the canvas, already turned, back into a drawing that keeps its angle and looks exactly the same. The algorithm (with R the rotation by `degrees`):
    1. `unturned` = each stroke with `transform.concatenating(rotation by −degrees about centre)`.
    2. `B` = `InkGeometry.bounds(of: unturned)`.
    3. `t = R(B.centre − centre) − (B.centre − centre)`, a shift that makes turning about the new frame's centre equal turning about the old one.
    4. Result: `frame = B.offsetBy(dx: t.x, dy: t.y)`, `ink = InkGeometry.data(for: unturned, measuredFrom: B.origin)`, `setRotation(degrees)`.
  - `DrawingSync.changes`: for an existing drawing whose `resolvedRotation != 0`, use `drawing(strokes, id: id, keepingTurn: known.resolvedRotation, about: known.frame.centre)`; new drawings stay upright. `Shown` is `(frame, ink, rotation)` everywhere it is built and compared, so turning a drawing re-places its strokes on the canvas.

**Interfaces:**
- Consumes: Tasks 1–3.
- Produces:
  - `ElementLayout.resizedTurned(_ frame: CGRect, degrees: Double, from corner: Corner, by translation: CGSize, kind: ElementKind) -> CGRect`. `translation` is in host points, as dragged on the glass. The algorithm:
    1. Turn the translation back by −degrees.
    2. `sized = resizedKeepingShape(frame, from: corner, by: thatTranslation, kind:)` for the new size `S'`.
    3. `W` = the old turned position of the corner opposite `corner`.
    4. `d'` = that opposite corner's offset from the centre in `sized`, turned by `degrees`.
    5. The new centre is `W − d'`, and the result is the rect of size `S'` round it.
    6. At 0° the result equals `resizedKeepingShape`.
  - AppModel:
    - `var canTurnSelection: Bool`: something is selected, no screen is among it, and at least one element is unlocked.
    - `func beginTurn()`: `store.beginHeldEdit()`, records the start angle, `isAdjusting = true`, `isTurning = true`.
    - `@discardableResult func turnSelection(by degrees: Double, snaps: Bool) -> Bool`: `degrees` is the total since `beginTurn`. Sets the angle to start + degrees (snapped when `snaps`). Returns whether it snapped, and sets the observed `snappedTurn: Double?`.
    - `func endTurn()`: `store.endHeldEdit()` and clears the flags.
    - `func rotateSelection(by degrees: Double)`: one step, no snapping.
    - `func resetSelectionTurn()`: back to 0°, one step.
    - `var selectionTurn: Double?`: the readout.
    - `var isTurning: Bool`.
    - `var selectionShape: TurnedRect?` in canvas points.
    - `static let knobStem: CGFloat = 28`, measured in view points from the outline's bottom edge to the knob's centre.
    - `var knobViewPoint: CGPoint?`: the view shape's centre plus `down × (height / 2 + knobStem)`; nil when `!canTurnSelection`.
    - `selectionViewRect` for a selection that can turn: the union of the view shape's `bounds` and a 44 × 44 square round `knobViewPoint`, so the popover keeps clear of the knob.
  - `struct RotateKnob: View`:
    - A 44 pt touch target, drawn like the corner handles (chrome fill, accent ring), on a 1.5 pt stem from the bottom edge's middle.
    - `accessibilityIdentifier("Rotate")`.
    - Drag: the angle comes from the pivot (the view shape's centre when the drag began) to the finger. Each move adds `shortestTurn` from the last angle, so turns past 180° accumulate; the total goes to `turnSelection(by:snaps: true)`.
    - A double tap calls `resetSelectionTurn()`.
    - Hidden while a move or resize drag is under way (`isAdjusting && !isTurning`).
  - Readout: "37°" (`selectionTurn` rounded) in a capsule beside the knob while `isTurning`.
  - Haptic: `.sensoryFeedback(.alignment, trigger: model.snappedTurn)` on the selection layer. The twist (Task 9) uses the same trigger.
  - Single element: outline and the four handles on the turned box. Handles resize with `resizedTurned`. The lock badge sits at the turned box's top-right corner.

### Task 5: Several things turn as one rigid piece, with no drift

**Files:**
- Create: `Layer/Model/TurnSession.swift`
- Modify: `Layer/App/AppModel.swift` (the turn API uses a session for `.several`; `selectionWillMove()` / `selectionMoved(by:)`)
- Modify: `Layer/Canvas/SelectionLayer.swift` (several: each member's outline turned, the dashed group outline as `selectionShape`, the knob; `moveSelection` tells the model it moved)
- Test: `LayerTests/RotationTests.swift`, suite `TurningSeveralThingsTests` (`TurnBoard`)

**Interfaces:**
- Consumes: Tasks 1–4.
- Produces: `struct TurnSession: Equatable`:
  - `let selection: CanvasSelection`.
  - `var pivot: CGPoint` (canvas).
  - `var outline: TurnedRect` (canvas, as formed).
  - `var turned: Double`.
  - A baseline per element member: its local frame, its angle and its placement.
  - `expected`: each member's frame and angle after our last turn or move.
  - Methods:
    - `static func form(for selection: CanvasSelection, in store: DesignStore) -> TurnSession?`:
      - nil when a screen is among the things or there is no element;
      - `outline` is `TurnedRect.enclosing(member shapes, at: a)`, where `a` is the members' shared angle, or 0 when they differ;
      - `pivot = outline.centre`;
      - locked members are in the baseline but are never moved.
    - `func placed(turnedBy degrees: Double) -> [DesignStore.ElementRef: (frame: CGRect, rotation: Double?)]`. For each unlocked member:
      - the angle is the baseline angle + degrees;
      - its baseline canvas centre is turned about `pivot`;
      - it's turned back into local points through its placement;
      - the origin is the centre − half its size, rounded to whole points unless it is a drawing;
      - when `Rotation.normalized(degrees) == 0`, it is exactly the baseline.
    - `func matches(_ store: DesignStore) -> Bool`: every member's current frame and angle equal `expected`.
    - `mutating func translate(by canvasDelta: CGSize)`: moves `pivot`, `outline` and the baseline (through each placement).
    - `var shape: TurnedRect`: `outline` at `outline.degrees + turned`.
  - AppModel holds `@ObservationIgnored private var turnSession: TurnSession?`:
    - It is used only while it is for the current selection and `matches(store)`; otherwise a fresh `form` is used. Nothing is stored from a view body.
    - `beginTurn` stores the session.
    - `turnSelection` sets `turned` and writes `placed(turnedBy:)` as one store change inside the held edit. Snapping snaps the outline's angle (`outline.degrees + turned`) to the 45s.
    - `resetSelectionTurn` turns to 0.
    - `selectionTurn` is `Rotation.normalized(turned)`.
    - `selectionShape` is the session's `shape`. This is a deliberate refinement of the spec's outline rule: it's the same at formation, but stays rigid during and after a turn, so the knob never jumps.
  - `func selectionWillMove()` / `func selectionMoved(by canvasDelta: CGSize)`: called by `CanvasDrags.moveSelection` at its first change and its end. If the session matched before the move, it is translated and `expected` is refreshed, so the pivot moves with the selection.

### Task 9: The two-finger twist, turn first

**Files:**
- Create: `Layer/Canvas/TwistGestureRecognizer.swift` (the classifier and the recogniser)
- Modify: `Layer/Canvas/InkCanvas.swift` (add it to the window beside `restingFingers`; target action; the canvases' pan and pinch wait for it to fail)
- Modify: `Layer/App/AppModel.swift` (`isOnSelection`, `interruptDrag`)
- Modify: `Layer/Canvas/SelectionLayer.swift` (`CanvasDrags` registers `interruptDrag` and ignores an `onEnded` after it)
- Test: `LayerTests/RotationTests.swift`, suite `TwistTests`

**Interfaces:**
- Consumes: the turn API (Tasks 4–5), `selectionShape`, `Viewport.viewShape(for:)`.
- Produces:
  - `enum TwistClassifier`:
    - `enum Decision { case undecided, twist, pinch }`.
    - `static let turnThreshold = 8.0` (degrees) and `static let spreadThreshold = 0.08`.
    - `static func turn(from start: (CGPoint, CGPoint), to now: (CGPoint, CGPoint)) -> Double`: signed and clockwise, via `Rotation.shortestTurn`.
    - `static func decide(from:to:) -> Decision`:
      - pinch when the distance ratio has moved ≥ 0.08 while the turn is < 8°;
      - twist when the turn is ≥ 8° while the ratio is still < 0.08;
      - when both thresholds are crossed in one update, whichever is further past its threshold, proportionally.
  - `final class TwistGestureRecognizer: UIGestureRecognizer`:
    - Configuration: `var isOnSelection: (CGPoint) -> Bool` (window points), `var canTurn: () -> Bool`, and `private(set) var turn: Double` (degrees since both fingers landed, so the element catches up with the first 8°).
    - It fails at once when:
      - `!canTurn()`;
      - a touch is a pencil;
      - the first touch isn't on the selection;
      - there is no second finger within 0.25 s, or the first finger moves more than 10 pt before the second lands;
      - the second finger isn't on the selection;
      - the classifier says pinch.
    - It begins when the classifier says twist. It changes on every move, ends when a finger lifts, and is cancelled by a third touch.
    - `cancelsTouchesInView = true`, so a drag on the element that had begun is cancelled when the twist wins.
  - Coordinator:
    - Adds it to the window where `restingFingers` is added.
    - Recognises simultaneously with `restingFingers`, `pencilDetector` and the palette flicks.
    - Calls `canvas.panGestureRecognizer.require(toFail: twist)` and `canvas.pinchGestureRecognizer?.require(toFail: twist)` for both canvases.
    - Action:
      - `.began`: `model.beginTurn()` then `model.interruptDrag()`, in that order, so a move already under way joins the turn's undo step.
      - `.changed`: `model.turnSelection(by: twist.turn, snaps: true)`.
      - Ended, cancelled or failed after beginning: `model.endTurn()`.
    - It works with Lock Canvas on.
  - `AppModel.isOnSelection(_ viewPoint: CGPoint) -> Bool`: the view shape of `selectionShape`, 8 pt larger all round, contains the point.
  - `@ObservationIgnored var interruptDrag: () -> Void = {}`. `CanvasDrags` sets it to end any drag in progress as if it had ended: origins cleared, guides cleared, `isAdjusting` false, `store.endEdit()`, no rehost. Its `onEnded` closures do nothing when their origin is already nil.
